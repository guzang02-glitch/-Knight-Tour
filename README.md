# 기사의 여행 (Knight's Journey)

L자 점프로 들판을 꽃밭으로 바꾸는 한붓그리기 퍼즐. 체스 나이트 이동(기사의 여행 문제)을 바탕으로, 바위로 경로를 줄이고 정답을 1개로 고정한 모바일 세로 화면용 웹 게임입니다.

## 실행

빌드 과정이 없는 단일 HTML입니다. `index.html`을 브라우저로 열거나, 아무 정적 서버로 이 폴더를 띄우면 됩니다.

```bash
npx serve .
```

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 게임 전체 (StageTable, StringTable 포함) |
| `img/` | 게임에서 쓰는 그림 |
| `assets/` | 그림 원본 (고해상도) |
| `docs/` | 시스템 기획서, 레벨 디자인 기획서 (MD) |
| `tools/` | 레벨 디자인 스크립트 (스테이지 seed 선정, 단일 해 검증) |

## 모드

- **스테이지**: 100개를 순서대로 진행, 보드 4×4 → 7×7 (1–10 4×4, 11–40 5×5, 41–80 6×6, 81–100 7×7). 모두 정답 1개, 경우의 수 1만 이하.
  끝자리 5, 0은 허들, 3, 8은 쉬어가는 길. 힌트는 기본 5개, 첫 클리어 +1, 0개일 때 광고 시청 +1.
- **체스 기물 칸**: 킹(21~), 룩(41~), 비숍(61~), 81~100은 전체. 기물 칸에 서 있을 때 다음 1회만 그 기물처럼 이동합니다.
  룩, 비숍은 바위에 막히고 꽃 칸은 지나갈 수 있습니다.
- **오답 길 표시**: 막혀서 되돌린 이동에 빨간 X가 남습니다(모든 길이 빨강이면 한 단계 위로 전파). 되돌려도 유지되고, 다시하기나 스테이지 이동 시 지워집니다.
- **수집 지표**: 스테이지 시도마다 PlayLog(결과 clear / restart / quit, 이동, 되돌리기, 힌트, 막힘, 기물 이동 직후 막힘 `piece_stuck_count`)와
  Player(가입, 마지막 접속, 현재 스테이지)를 기록합니다. 주소 끝에 `#metrics`를 붙이면 업데이트 제안서 4.1의 지표 7개를 보고 로그를 JSON으로 내보낼 수 있고,
  여러 유저의 로그는 `node tools/metrics.js index.html 로그1.json 로그2.json …`로 합쳐 계산합니다.
  claude.ai에서 열면 소유자와 편집자는 상단 막대그래프 버튼으로 모든 플레이어의 지표를 봅니다.
